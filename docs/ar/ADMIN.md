# دليل الإدارة

[English](../ADMIN_GUIDE.md) | [العربية](ADMIN.md)

ادخل بحساب مخوّل إلى `/admin/overview`. الأرقام مصدرها قاعدة البيانات وفحوص الخدمات، وليست بيانات عرض مصطنعة. تُظهر الصور المرفقة نشاط بيئة تجريبية فقط.

| الشاشة | الاستخدام |
|---|---|
| النظرة العامة | الملفات والسعة والرفع والحسابات وصحة الخدمات والمهام واستهلاك الموارد |
| الملفات والرفع والمشاركة | البحث والفحص والمنع والاستعادة وإنهاء الرفع غير المكتمل وإدارة صلاحية الروابط |
| المستخدمون والخطط | تفعيل الحساب بمعرّف AF، التعليق وإلغاء الجلسات والحصص والخطط والاستثناءات |
| التخزين | الصحة والسعة والكمون والكائنات والمطابقة، دون عرض بيانات الاعتماد |
| الأمان والتدقيق | أحداث الدخول والحدود وبلاغات الإساءة والحظر وسجل العمليات |
| المهام والإشعارات | فحص حالة المهام ومحاولاتها وإعادة المحاولة بعد معالجة السبب |
| الصفحات وSEO | محتوى قانوني باللغتين ومسودات ونشر وإصدارات وبيانات محركات البحث |
| صندوق الدعم | بحث وتصنيف وإسناد وملاحظات خاصة وردود وإغلاق وإعادة فتح |
| الإعدادات وصحة النظام | سياسات الرفع والمشاركة والحسابات والسعة والمظهر والصيانة وجاهزية الاعتماديات |

يتحكم OWNER في رفع الأدوار، وتُحمى آخر هوية مالك نشطة. يدير ADMIN المستخدمين والإعدادات والمهام، ويملك MODERATOR صلاحيات الإشراف، ويمكن لـ SUPPORT قراءة الشاشات المسموحة وإدارة محادثات الدعم. لا يكفي ظهور زر في الواجهة للحصول على صلاحية؛ القرار للخادم.

## الحسابات والخطط

الحسابات الجديدة PENDING حتى تفعيلها بمعرّف الحساب؛ لا يُعرض البريد الصريح. التخزين الافتراضي FREE هو 200 GiB وPRO هو 2 TiB، ويمكن تعديل كل حد بصورة مستقلة. استثناءات الحساب لا تزول عند تغيير الخطة إلا بإزالتها صراحة. لا توجد معالجة دفع، وزيادة الحصص لا تضيف مساحة تخزين.

من صفحة الحساب يستطيع المستخدم تغيير كلمة المرور وإدارة الأجهزة والجلسات ومفاتيح API. يظهر المفتاح الجديد مرة واحدة. يلزم الحفاظ على جلسة الضيف لاستمرار إدارة ملفاته؛ يرقّي التسجيل مساحة الضيف دون نقل بايتات الملفات.

## الملفات والقياس

يمنع حظر الكائن إصدار تنزيلات جديدة لنسخه، لكن الروابط الموقعة السابقة تستمر حتى انتهائها. يتطلب الحذف النهائي الانتقال إلى السلة والتأكيد؛ لا يُحذف الكائن ما دام مرجع باقٍ يحتاج إليه. الوضعان المقيد والصيانة يحافظان على التنزيل مع تقييد التغييرات.

تمثل إحصاءات التنزيل حجوزات تفويض، لا بايتات الشبكة المكتملة. تُؤخذ معدلات التخزين بعينات كل 10 ثوانٍ بعد انتهاء الطلبات وتشمل قراءات التحقق الخلفية.

## المحتوى والدعم

تحفظ Pages & legal مسودات عربية وإنجليزية منقّحة، ولا يستبدل حفظ المسودة المحتوى المنشور. استعادة إصدار تنشئ مسودة تحتاج إلى نشر منفصل. اضبط canonical وrobots وخريطة الموقع وصور المشاركة من SEO؛ التتبع معطل حتى دمج الموافقة، والصفحات الخاصة غير مفهرسة.

يدعم صندوق الاتصال الردود داخل التطبيق دون SMTP. يستخدم الضيف رابط قدرة سريًا، بينما ترتبط تذاكر الحساب بمعرّفه. تنتهي التذاكر المغلقة بعد 90 يومًا. احمِ الملاحظات والمحتوى ولا تنشرها ضمن تقارير الأعطال. [الدليل الكامل](../ADMIN_GUIDE.md).
