# الأمان والخصوصية

[English](../SECURITY.md) | [العربية](SECURITY.md)

تستخدم كلمات المرور Argon2id بذاكرة 64 MiB وثلاث دورات، ولا تُخزّن بصورتها الأصلية أو بتشفير قابل للعكس. تُحفظ بصمات أسرار الجلسات ومفاتيح API، وتستخدم الجلسات ملفات ارتباط HttpOnly وSameSite وSecure عند HTTPS. يتطلب إنشاء المالك الأول رمزًا مولدًا، ولا توجد كلمة مرور افتراضية.

يتحقق الخادم من الأدوار والملكية والحصص ونطاقات المفاتيح. تتطلب طلبات التعديل بالجلسات تطابق Origin وترويسة `X-Astra-Client: web`. تُفحص المدخلات عبر Zod وتستخدم SQL معاملات مربوطة. لا تتيح مفاتيح API الوصول إلى الإدارة أو الجلسات.

## حدود المشاركة

تحتوي الروابط الجديدة على أسرار fragment عشوائية من 256 بت، ولا تُحفظ إلا بصماتها المقيّدة بمفتاح. يُستبدل السر بعد حله بملف ارتباط قصير الأجل ويزال من عنوان المتصفح. فقدان الرابط يتطلب تجديده. معرّف الحساب العام لا يصادق المستخدم.

يمنع إلغاء المشاركة أو تعليق الحساب إصدار روابط تنزيل جديدة؛ الرابط الموقّع الصادر مسبقًا يبقى صالحًا حتى 15 دقيقة. يمكن إعادة استخدامه وطلب Range خلال صلاحيته. العدادات والحصص تقيس التفويضات والبايتات المحجوزة، لا الاتصالات المفتوحة أو البايتات الفعلية على الشبكة.

## البيانات والمفاتيح

يستخدم البريد فهرس HMAC دون حفظ العنوان الصريح، وتُشفّر حقول مختارة عبر AES-256-GCM المرتبط بالسجل. تفصل مجموعات مفاتيح ذات إصدارات بين البحث والمشاركة والحقول والشبكة والنسخ. احتفظ بالإصدارات اللازمة لفك البيانات القديمة ولا تستخدم المفتاح نفسه لأغراض مختلفة.

هذه ليست بنية عديمة المعرفة أو تشفيرًا طرفيًا: يستطيع الخادم قراءة الملفات المرفوعة. لا تشمل حماية البيانات الوصفية تشفير بايتات ملفات المستخدم من الطرف إلى الطرف. [خريطة البيانات والاحتفاظ](../PRIVACY_DATA_MAP.md).

## التشغيل

استخدم تخزينًا خاصًا وCORS للأصل الدقيق وشهادة HTTPS موثوقة. الشهادة الذاتية الأولية مناسبة لإعداد مضبوط فقط. فحص الملفات اختياري ويتطلب `SCAN_COMMAND` وتفعيل السياسة؛ لا يفك التطبيق الأرشيفات. SMTP اختياري لاستعادة البريد، والنسخ الوصفية لا تتضمن الملفات.

استبعد الأسرار وأجسام الطلبات والروابط الموقعة من السجلات. لا ترفع `.env` أو المفاتيح أو النسخ أو ملفات المستخدمين أو حالة المتصفح إلى Git. إذا نُشرت بيانات اعتماد، ألغها أو دوّرها ونقّح التاريخ؛ حذف الملف الحالي وحده لا يكفي.

لإبلاغ ثغرة، اتبع [سياسة الإبلاغ الخاصة](../../SECURITY.md) ونسّق سرًا قبل النشر العام. لا توجد جهة اتصال بريدية عامة محددة ولا ضمان زمني للاستجابة. [النموذج الأمني الكامل](../SECURITY.md).
