# الإعدادات

[English](../CONFIGURATION.md) | [العربية](CONFIGURATION.md)

المرجع المعتمد هو [`.env.example`](../../.env.example). يحتوي على أمثلة بديلة، وليس بيانات اعتماد جاهزة. احتفظ بالقيم الحقيقية في ملف بيئة محمي وأعد تشغيل API والعامل بعد تغيير متغيراته. إعدادات لوحة التحكم محفوظة في PostgreSQL.

| المجموعة | المتغيرات والمتطلبات |
|---|---|
| التطبيق والشبكة | `NODE_ENV` افتراضيًا development؛ `APP_ORIGIN` افتراضيًا `http://localhost:18400` ويتطلب HTTPS في الإنتاج؛ `HOST` افتراضيًا `127.0.0.1` و`PORT` هو 18402؛ حدّد `TRUST_PROXY` للوكلاء الموثوقين فقط |
| قاعدة البيانات وRedis | `DATABASE_URL` و`REDIS_URL` مطلوبان دون قيمة افتراضية؛ `POSTGRES_PASSWORD` يخص Compose المحلي، ويقرأ Redis إعداداته من ملف محمي |
| التخزين | `S3_ENDPOINT` للخادم و`S3_PUBLIC_ENDPOINT` للمتصفح مطلوبان، وكذلك `S3_ACCESS_KEY` و`S3_SECRET_KEY` و`STORAGE_DISK_PATH`؛ الحاوية الافتراضية `astrafile` والمنطقة `us-east-1`؛ `S3_METRICS_ENDPOINT` اختياري |
| المصادقة | `COOKIE_SECRET` مستقل بطول 32 محرفًا على الأقل؛ `BOOTSTRAP_TOKEN_HASH` بصمة SHA-256 بطول 64 محرفًا لرمز التهيئة المحفوظ بصورة منفصلة |
| البريد | `SMTP_URL` اختياري؛ اضبط `MAIL_FROM` بعنوان إرسال معتمد عند تفعيل البريد |
| الفحص والنسخ | `SCAN_COMMAND` اختياري مع تفعيل الفحص من الإدارة؛ `BACKUP_ENABLED=true` لتفعيل النسخ، و`BACKUP_DIR` لمسار قابل للكتابة؛ قالب الإنتاج يفعّل النسخ |

## مفاتيح الخصوصية

المجموعات الخمس المطلوبة هي `EMAIL_LOOKUP_KEYS` و`SHARE_LOOKUP_KEYS` و`FIELD_ENCRYPTION_KEYS` و`NETWORK_PRIVACY_KEYS` و`BACKUP_ENCRYPTION_KEYS`. لكل غرض مفتاح مستقل من 32 بايت، ضمن JSON يحدد الإصدار النشط والإصدارات المحتفظ بها. ينشئها الإعداد المحلي أو التهيئة الإنتاجية دون طباعتها.

يضيف الأمر التالي المجموعات المفقودة فقط إلى ملف محمي، ولا يستبدل المفاتيح الحالية:

```sh
node scripts/setup-privacy-keys.mjs .env
```

لا تحذف إصدارًا قديمًا ما دامت بيانات أو نسخ مشفرة تحتاج إليه. وقد يلزم الاحتفاظ بمفتاح البحث السابق للحسابات غير النشطة. [تفاصيل التدوير](../PRIVACY_DATA_MAP.md#keys-and-rotation).

## السياسات التي تُدار من الواجهة

حجم الجزء الافتراضي 64 MiB والتوازي 4، مع خيارات 32/64/128/256 MiB وتوازٍ من 1 إلى 8. تنتهي عمليات الرفع غير المكتملة بعد 72 ساعة افتراضيًا، واحتفاظ الضيوف 7 أيام، والسلة 30 يومًا، والمشاركة 168 ساعة، والجلسة 30 يومًا بحد أقصى 20 جلسة. الإصدارات مفعلة افتراضيًا بحد 20 إصدارًا و90 يومًا.

الخطط والحصص والمظهر واللغة وSEO إعدادات قاعدة بيانات، وليست متغيرات بيئة مستحدثة. تخزين FREE الافتراضي 200 GiB وPRO هو 2 TiB، مع حدود مستقلة واستثناءات للحسابات. حد المساحة الحرة الافتراضي 15 GiB والتنبيه 20 GiB. زيادة الحصة لا تضيف أقراصًا. يتطلب التسجيل الجديد تفعيلًا يدويًا في هذا الإصدار.

لا يعمل إرسال استعادة كلمة المرور دون SMTP، لكن الدعم داخل التطبيق لا يحتاجه. لا يُعد غياب ماسح مهيأ ضمانًا لفحص الملفات. النسخ الوصفية لا تتضمن بايتات الملفات. اضبط SEO والمحتوى باللغتين من الإدارة؛ التتبع معطل إلى حين دمج الموافقة.

في الإنتاج يحدد `ASTRAFILE_RELEASE` إصدار الصورة، وتحدد `APP_ORIGIN` و`ASTRAFILE_BIND_IP` و`ASTRAFILE_HTTPS_PORT` عنوان الخدمة. منفذ HTTPS الافتراضي 18443 ومنفذ التخزين القديم 18444 محلي فقط. راجع [المرجع الكامل لجميع القيم والمتطلبات](../CONFIGURATION.md).
