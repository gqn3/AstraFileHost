# التثبيت المحلي

[English](../INSTALLATION.md) | [العربية](INSTALLATION.md)

تحتاج إلى Node.js 22.12 أو أحدث، وnpm وGit، وDocker يعمل بوضع حاويات Linux مع Compose v2. وفّر 40 GiB على الأقل كبداية للنشر المرجعي، مع مساحة إضافية للملفات والنسخ. حد المساحة الحرة الافتراضي لقبول الرفع 15 GiB وقابل للتعديل.

## تثبيت جديد

```sh
git clone https://github.com/gqn3/AstraFileHost.git
cd AstraFileHost
npm ci
npm run setup:local
docker compose --env-file .env -f infra/compose/local.yml up -d --build --wait
npm run migrate
npm run storage:init
npm run dev
```

يتطلب المستودع الخاص صلاحية وصول. أبقِ اسم المجلد `AstraFileHost` لأن سكربت الإعداد يتحقق من النطاق. ينشئ `setup:local` ملف `.env` ومجلدي `.secrets` و`.local` بأسرار عشوائية مستقلة، ويرفض استبدال `.env` قائم. لا تنسخ ملف المثال أولًا في هذا المسار.

افتح `http://localhost:18400/setup`. اقرأ رمز `.secrets/bootstrap-token` على جهازك وأدخله مع بيانات حساب المالك التي تختارها. لا تنشر الرمز أو تضعه في تذكرة دعم. إنشاء حسابات لاحقة يتطلب تفعيلًا إداريًا بمعرّف الحساب.

يشغّل `npm run dev` الواجهة وAPI والعامل الخلفي. تحقّق من `/health/ready`؛ ظهور الواجهة لا يكفي للتأكد من سلامة الخدمات. المنافذ المحلية هي 18400 للواجهة و18402 لـ API و18432 لقاعدة البيانات و18479 لـ Redis و18401 للتخزين و18403 لمقاييسه، وكلها محلية في القالب.

## التشغيل اللاحق

احتفظ بالأسرار والأحجام التخزينية. لا تعِد التهيئة الأولى، ولا تغيّر مفاتيح التشفير لحل مشكلة تشغيل. طبّق الترحيلات اللازمة بعد النسخ الاحتياطي المناسب. لإيقاف الخدمات دون حذف بياناتها:

```sh
docker compose --env-file .env -f infra/compose/local.yml stop
```

يمكن بدل الإعداد التلقائي نسخ `.env.example` يدويًا وضبط جميع متغيرات [الإعدادات](CONFIGURATION.md). يضيف `node scripts/setup-privacy-keys.mjs .env` مجموعات مفاتيح الخصوصية المفقودة فقط؛ لا ينشئ بقية بيانات الاعتماد أو الخدمات. أما قالب Compose المحلي فيحتاج ملفات الأسرار التي ينشئها الإعداد التلقائي. [النشر الإنتاجي](DEPLOYMENT.md) مسار منفصل خاص بـ Linux.
